# 阅读冒险岛 📚🏝️

一款面向**小学三年级**的语文阅读教育游戏。纯静态网页，无需后端、无需联网（拼音库已本地化），手机 / 平板 / PC 浏览器均可使用。

## ✨ 功能特色

- **300 篇阅读材料**：童话、寓言、民间故事、历史故事、神话传说、科学家故事、科普短文、自然现象、节气文化、校园成长、情绪心理、古诗赏析、写作表达等题材，每篇约 590–980 字，累计约 22 万字
- **十星难度阶梯**：一至十星各 30 篇，从图文短文逐步过渡到概括赏析、思辨迁移与综合创作；前一星级全部完成后解锁下一星级
- **🔤 拼音模式**：一键开关，每个汉字上方显示带声调的拼音（多音字按上下文智能注音，经全库逐字审计）
- **🔊 朗读模式**：6 种预置音色（小女孩 / 小男孩各 3 种）随心切换，支持试听，标准普通话朗读，自动翻页连读
- **互动阅读**：读后理解小题、情节选择、句子重组、创意写作
- **成长系统**：阅读时长统计、词汇宝盒（1318 个生词）、阅读等级、连续打卡、徽章奖励
- **家长监控**：家长口令进入，查看每日阅读时长、阅读量、词汇掌握与答题正确率

## 🚀 本地使用

直接双击打开 `index.html` 即可开始游戏，无需安装任何东西。

> 💡 朗读功能推荐使用 **Microsoft Edge** 或 **Chrome** 浏览器（自带高质量中文语音，Edge 的"晓晓""云夏"音色最接近小女孩）。

## 🌐 GitHub Pages 部署

```bash
git init
git add .
git commit -m "阅读冒险岛 v1.0"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

然后到仓库 **Settings → Pages**，Source 选择 `main` 分支 / `(root)`，保存后稍等 1–2 分钟，访问：

```
https://<你的用户名>.github.io/<仓库名>/
```

## 🎯 教育目标对应

| 目标 | 游戏内机制 |
|---|---|
| 每日阅读 ≥ 20 分钟 | 首页 20 分钟进度环 + 达标提醒 |
| 学期阅读量 ≥ 5 万字 | 累计字数约 22 万字，逐字统计 |
| 常用汉字 +500 | 1318 个生词（带拼音释义）可点击收藏进宝盒 |
| 阅读理解提升 | 每篇 4 道理解题，正确率家长端可查 |
| 自主阅读习惯 | 连续打卡、等级徽章、情节选择的沉浸式体验 |

## 🔧 技术说明

- 纯 HTML / CSS / JavaScript，零依赖、零构建
- 存档保存在浏览器 `localStorage`，换设备/清缓存会重置进度
- 拼音引擎：[pinyin-pro](https://github.com/zh-lx/pinyin-pro)（MIT License）
- 朗读：浏览器 Web Speech API（音色取决于设备系统语音）
